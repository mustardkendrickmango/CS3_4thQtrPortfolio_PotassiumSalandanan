### Step 1 (Static vs Relative):

- Add in css ```position: relative; top: 20px; left: 20px;``` to .sidebar.

- Guided Question: What changed compared to the default static positioning? Try to give different values to top and left or you can change it to bottom, right.

1. Static positioning always aligns elements to the left-most part of the viewport. Relative positioning moves an element by given values relative to its original static position.

### Step 2 (Fixed):

- Add in css ```position: fixed; bottom: 0; width: 100%;``` to .footer.

- Guided Question: What happens when you scroll the page? Why does the footer behave differently from position relative?

2. Scrolling keeps the position of the element fixed relative to the viewport. Fixed position is relative to the viewport whereas relative position is relative to the static position of an element.


### Step 3 (Absolute):

- Add in css ```position: absolute; top: 66px; left: 200px;``` to .content.

- Guided Question: What is the effect of position: absolute on an element? How is it different from fixed?

3. Position: absolute adjusts an element based on the values you put relative to the nearest positioned ancestor in that direction. Absolute is different from fixed because absolute positioning is relative to its close-range elements while fixed positioning maintains the position of an object relative to the viewport. Fixed positions stay in place when you scroll.


### Step 4 : (Absolute)

- Add in html ```<div class="notice">Notice!</div>``` and include the css below:

```css
.notice {
    position: absolute;
    top: 60px;
    left: 400px;
    background: orange;
    padding: 10px;
    z-index: 2;
}
```

- Give .content a z-index: 1.

- Guided Question: Why does the notice appear on top of the content? What happens if you swap the z‑index values?

4. Z-index value determines the layer of the element. A higher z-index has a higher priority to go above those with a lower value. Swapping the z-indexes results in the content overlapping notice.

3. Please answer the following reflection questions (15 minutes)

    a. Could you summarize the differences between the CSS position values (static, relative, absolute, fixed)? 

a. 
Static - original position is aligned to the left most of the viewport
Relative - position is adjusted relative to the static position
Absolute - position is relative to the nearest positioned ancestor elements
Fixed - relative to the viewport and stays in place when you scroll



    b. How does absolute positioning depend on its parent element?

b. Absolute positioning is relative to its nearest ancestor(parent,grandparent,etc) element in a certain direction


    c. How do you differentiate sticky from fixed (you can research on sticky)?


c. Sticky is like fixed+relative meaning in the original viewport, the position is relative but when you scroll, the element stays in that position in the viewport making it fixed. Sticky allows the element to remain on the assigned position on the viewport even while scrolling whereas fixed only maintains the position of the element on the viewport but isn't maintained when you scroll.



    d. If you were designing a webpage for a school event, how might you use positioning to highlight important information? Please give concrete examples.


d. You can use positioning to highlight information by placing elements in such a way that it is eye-catching and tells you what you need. For example, you want the navigation bar of different content on your page to be fixed to the top of the screen even when you scroll so that the user may easily access other pages or use z-index in creating layers to your content on the page so your information is arranged in order or such.
